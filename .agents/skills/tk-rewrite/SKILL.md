# 文案三步（外语 → 中文 → 中文调整稿）

一句话：**机器做执行，人做判断；做到 03 就停。**

## 输入

- 素材：`02-去水印/<id>-clean.mp4`（没有就用 `01-素材/<id>.mp4`）
- 输出目录：`03-文案/<id>/`
- 语种：用 `--lang` 指定（en / ja / ko / zh），不知道先试 auto

## 三步

```bash
KIT="${KIT:-$HOME/tk-kit/kit}"; ROOT="$HOME/Desktop/TK素材"
D="$ROOT/<年-月>/<年-月-日>/<编号>-<id>/03-文案"

# ① 转写（脚本，不许自己听写）
HF_HOME=$PWD/.cache/hf $KIT/.venv-asr/bin/python $KIT/transcribe.py \
  "$ROOT/.../<id>/02-去水印/<id>-clean.mp4" --lang en --out "$D"
# 产出 01-英文稿.txt + 01-英文稿.srt
```

② 初翻（英文 → 中文）写 `02-中文稿.txt`：

1. 按中文习惯表达，不生硬直译，不改变叙事顺序
2. **语句之间不加任何标点**
3. **一句一行，行数与 01 完全一致**（不合并、不拆分）
4. 血腥暴力词改中性说法
5. 自检：行数相等？有没有混入标点？

③ 改写（中文 → 调整稿）写 `03-调整稿.txt`：

1. 改成「准备翻日语」的口播中文：短句、直给
2. 不用成语、歇后语、网络梗
3. 不加标点，一句一行，**行数与 02 一致**
4. **总字数比 02 少 30% 以上**
5. 开头三句必须是钩子：冲突 / 反常识 / 悬念
6. 允许倒叙：先给结果再回去讲原因（画面需配合重排）

## 发布文案（标题 / 正文 / 标签）

在三步之外，额外产出一份 `发布文案.txt`（跟 03 放同一个目录），**给发布用，不参与配音**：

```
第 1 行 = 标题（一句话）
第 2 行 = 正文（一句话，短）
第 3 行 = 标签
```

规则：

1. **标题一句话**：钩子优先（冲突/反常识/悬念），不写问句堆叠，不超过 40 个日文字符
2. **正文一句话**：补信息或抛问题，不超过 60 个日文字符，不重复标题
3. **标签 ≤ 5 个**，其中 **`#速報` 和 `#news` 必须有**，剩下 3 个按题材选（`#海外ニュース` `#感動` `#涙` 这类）
4. 语言跟成片一致（日语片写日语），专有名词保留原文
5. 不堆 emoji，不写「必ず見て」这类诱骗词

样例：

```
電車のドアが閉まった瞬間、ホームに残されたのは赤ちゃんだけだった
車内に取り残された母親は窓を叩き、通りかかった男が代わりに赤ちゃんを守っていた。
#速報 #news #海外ニュース #感動 #涙
```

## 门禁（只认文件名）

- 有 `03-调整稿.txt`、没有 `04-已审核.txt` → **停下问「审完了吗」**
- **AI 绝对不许自己生成 `04-已审核.txt`**，那等于绕过人审
- 有 `04` 才能进日文稿（`tk-dub` 上游）

## 校验（跑完必须过）

```bash
KIT="${KIT:-$HOME/tk-kit/kit}"
.venv/bin/python "$KIT/rewrite_check.py" "$D"
```

检查四项：行数 01=02=03、02/03 无标点、缩减 ≥30%、空行。

## 产出

```
03-文案/<id>/
├── 01-英文稿.txt / .srt
├── 02-中文稿.txt
├── 03-调整稿.txt
├── 03-说明.txt      钩子 + 疑点（人名/数字/地名/看不懂的）
└── index.json       {"01":…,"02":…,"03":…,"guard":"03"}
```

`03-说明.txt` 必须写：**钩子三句** + **疑点**（原片没给的数字、性别、地名），并标明哪些是画面推断。

## 边界

- 不编情节：原片没说的不补
- 不顺着评论区写（评论是「观众以为」，不是事实）
- 不做日语（那是 `tk-dub` 上游之前的独立一步）
