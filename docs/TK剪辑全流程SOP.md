# TK 剪辑全流程 SOP

> **一句话记住**：01 找素材决定「有没有东西可剪」；02 处理素材决定「说不说得清、像不像人」；03 剪辑成片决定「能不能发、有没有人看」。

| 项目 | 内容 |
| --- | --- |
| 适用场景 | 日语市场二创剪辑：外语原片 → 中文脚本 → 日语配音 → 剪映成片 |
| 谁来用 | 新剪辑照着走；老人当发布前检查清单 |
| 配套文件 | `projects/tk-sop/flow.html`（流程海报，一页版） |
| 版本 | v1.0 · 2026-10-31 |

## 0. 全流程一张图

```
① 找素材            ② 处理素材                     ③ 剪辑成片
TK 网页版           2.1 字幕 & 文案                1 剪画面（卡点）
  ↓                 剪映 → 字幕 → 中文 → txt        2 换字体（不用系统字）
关注同类账号          → GPT 改写 → 日语              3 BGM 加速
  ↓                 2.2 日语配音                    4 贴纸 / 滤镜
挑高观看率           声音样本 → Minimax 克隆         5 去水印
  ↓                  → 生成配音 → 下载              ↓
复制链接             2.3 收尾 & 对轴                 发布前 6 项检查
  ↓                 pc404/DSH 去气口 → JingleBox 对轴
哼哼猫 / Snaptik     → 配音+字幕回剪映
  ↓
1 条原片            脚本 + 配音 + 字幕               可发布成片
```

三个阶段各有一个硬卡点：**素材不对，后面全白做；气口和轴不干净，成片就"假"；红线和检查不过，发了也白搭。**

## 1. 阶段一：找素材

**产出**：1 条可剪原片（原链接 + 无字幕、无音频的视频文件）

### 1.1 操作步骤

1. **登录 TK 网页版**。Web 端找视频、看数据都比 App 方便，别在手机上翻。
2. **关注同类型账号**，先建"对标账号"库，不要凭感觉刷到哪条算哪条。
3. **找高观看率的视频**：优先近期（近 30 天）、结构可复制、非敏感题材。
4. **复制视频链接**：拿原链接，不用录屏。
5. **哼哼猫 / Snaptik 下载**：只要视频画面，不下载字幕和音频。

### 1.2 什么样的素材才算"对"

- **同赛道**：和你要做的方向、语言、受众一致，别拿美食号去改知识口播。
- **数据够**：观看率明显高于该账号平时水平，而不是碰巧点赞多。
- **结构可复制**：口播、展示、剧情三段式都行，但必须是"换个说法还能成立"的结构。
- **不是敏感题**：暴力血腥、政治、医疗绝对化表述，一律不碰。
- **去字幕后看得懂**：如果原片信息全压在字幕上，去掉字幕就废，说明它依赖原文，不适合二创。

### 1.3 卡点与常见坑

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 素材和赛道不搭 | 后面全白做 | 先定赛道，再挑视频 |
| 用录屏代替下载 | 画质差、带自己界面、帧率不稳 | 一律用原链接下载 |
| 连字幕音频一起下 | 平台容易判定重复 | 只下视频轨 |
| 挑太老的爆款 | 结构已经过期，观众见过 | 优先近 30 天 |

## 2. 阶段二：处理素材

**产出**：中文脚本（改写后）+ 日语配音 + 对齐的字幕

这一段决定两件事：**说什么（脚本）** 和 **谁来说（声音）**。

### 2.1 字幕 & 文案

1. 素材导入 **剪映**。
2. 自动生成字幕。
3. 字幕翻译成中文。
4. 导出**字幕 txt**。
5. 用 **GPT 简化 / 改写**：去重、重写开头钩子。
6. 人工调整，再译成日语。

**关键判断**

- **开头 3 秒必须有钩子**：前 3 秒没抓住人，后面做得再好也没人看到。
- **改写幅度要够**：不只是换同义词，要换句式、换叙述顺序、换例子，防止平台判定重复度过高。
- **改完要通读一遍**：机翻 + GPT 出来的句子经常"每个字都对，连起来不像人话"。

### 2.2 日语配音

1. 找合适的声音样本，下载并提取音频。
2. 海外版 **Minimax** 克隆声音（新号有 3 次免费额度）。
3. 用克隆出来的声音生成日语配音。
4. 下载配音文件。

**关键判断**：先定"谁在说"，再生成。声音不贴内容（比如讲知识用了很嗨的带货音），后面很难救。

### 2.3 收尾 & 对轴

1. **去气口**：pc404 或 DSH 剪辑。
2. **字幕音频对轴**：JingleBox。
3. 配音 + 字幕一起导回剪映。

**卡点**：气口没剪干净、字幕和配音对不上，成片会"假"——观众说不出哪里不对，但就是不想看完。

| 问题 | 表现 | 处理 |
| --- | --- | --- |
| 气口没剪干净 | 每句话之间都有半秒空白，节奏拖 | 逐句剪掉首尾静音，保留 0.1–0.2 秒呼吸感 |
| 字幕和配音不齐 | 字先出、声后到，或反过来 | JingleBox 对轴后回剪映再校一遍 |
| 声音不贴 | 语气和内容打架 | 换声音样本重克隆，别硬调 |

## 3. 阶段三：剪辑成片

**产出**：可直接发布的成片

1. **剪画面**：按文案节奏卡点，删废话。
2. **换字体**：不要用系统字体，全片统一风格。
3. **BGM 加速**：提高节奏，避免拖沓。
4. **贴纸 / 滤镜**：补画面、遮瑕疵、统一质感。
5. **去水印**：调整画面大小，或用贴纸遮挡。

### 四条红线

| 红线 | 原因 |
| --- | --- |
| 不要暴力血腥画面 | 平台直接限流或下架 |
| 字体不要用系统的 | 一眼"搬运感"，也不统一 |
| BGM 要加速 | 原速 BGM 会把节奏拖死 |
| 不要出现别人的水印 | 既违规又掉信任 |

---

## 4. 发布前 6 项检查

发之前逐条打勾，**任何一条不过就不要发**。

| # | 检查项 | 通过标准 | 不过怎么办 |
| --- | --- | --- | --- |
| 1 | 开头 3 秒有钩子 | 前 3 秒有冲突 / 悬念 / 反常识 | 重写第一句，重配音 |
| 2 | 文案改到不像原片 | 句式、例子、顺序都换过 | 回 2.1 重改 |
| 3 | 气口剪干净 | 无长段静音，节奏不拖 | 回 2.3 去气口 |
| 4 | 字幕配音对轴 | 声画同步，无提前/滞后 | JingleBox 重对 |
| 5 | 字体 / BGM / 贴纸统一 | 全片一套风格 | 统一替换 |
| 6 | 无水印、无血腥、无违规 | 画面干净，内容可过审 | 遮挡或换素材 |

## 5. 一条片的工时预算

> 起步参考值，跑满 3 条后按实际耗时校准。目的是让你知道"卡在哪一步"，而不是拿来考核。

| 阶段 | 主要动作 | 参考工时 |
| --- | --- | --- |
| 01 找素材 | 刷号、筛数据、下载 | 30–45 分钟 |
| 02 处理素材 | 字幕翻译、GPT 改写、配音、对轴 | 60–90 分钟 |
| 03 剪辑成片 | 剪画面、换字体、BGM、贴纸、去水印 | 60–90 分钟 |
| 发布前检查 | 6 项逐条过 | 10 分钟 |
| **合计** | | **约 3 小时 / 条** |

如果某一步明显超时，先别加人，先看是不是素材选错了——**80% 的超时来自阶段一**。

## 附录 A：对标账号库字段

建表时至少记这几列，方便回头复用，而不是每次重新刷：

| 字段 | 说明 |
| --- | --- |
| 账号名 / 链接 | 原账号，便于回访 |
| 赛道 | 知识、生活、剧情、测评…… |
| 语言 / 地区 | 决定配音和字幕语言 |
| 粉丝量级 | 判断是"个人号跑出来"还是"机构号" |
| 近期高播放视频 | 记 3 条，附链接和播放量 |
| 可复制结构 | 一句话写清楚它靠什么成立 |
| 是否已用过 | 避免重复剪同一条 |

## 附录 B：脚本结构模板

```
【0–3 秒】钩子：一句反常识 / 一个冲突 / 一个具体数字
【3–15 秒】铺垫：为什么会这样（给一个具体场景）
【15–45 秒】主体：3 个点，每点一句结论 + 一个例子
【45–55 秒】收尾：一句可记住的话 + 一个动作引导
```

写日语版时不要逐句直译：**先保证中文逻辑顺，再让日语说得像日本人会说的话。**

## 附录 C：术语表

| 词 | 意思 |
| --- | --- |
| 气口 | 说话之间的停顿、吸气声、静音段 |
| 对轴 | 让字幕出现的时间和配音对齐 |
| 二创 / 剪辑 | 拿别人的原片，重写文案、重配音、重剪 |
| 卡点 | 画面切换和文案节奏对齐的位置 |
| 铺号 | 大量开号批量发同一类内容（本 SOP 不走这条路） |
